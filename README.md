# Hospital-Management
**Hospital Management System** is a web-based application that manages hospital operations, including patient records, doctor management, appointments, and billing. It provides secure, role-based access for Admin, Doctor, and Patient, making hospital management faster, organized, and efficient.

# 📖 Overview

The **Hospital Management System** is a secure and scalable web application designed to automate hospital operations. It enables hospitals to efficiently manage patients, doctors, appointments, billing, and user authentication through dedicated dashboards.

# 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/cyrus1006/Hospital-Management-System.git
```

### Install Frontend

```bash
cd frontend
npm install
npm run dev
```

### Install Backend

```bash
cd backend
npm install
npm start
```

---

# ⚙️ Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000

MONGO_URI=mongodb://localhost:27017/hospital_management

JWT_SECRET=your_secret_key

JWT_EXPIRES_IN=7d
```
